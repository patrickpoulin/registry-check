Registry Check

Type a word. See it on .love and other top-level domains, and find out which ones are still free.

Separate words with commas. Spaces inside a phrase are removed, so “true love” becomes truelove.

Domains to check

Checks run in your browser. Each name is looked up in the registry's public RDAP service, with a DNS check as a backup when a registry has no RDAP. “Available” means the registry has no record of the name; premium or reserved names can still be priced differently or blocked, so confirm with a registrar before you get attached.
